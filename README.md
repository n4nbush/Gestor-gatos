# 💰 Gestor de Gastos Personales

Aplicación web para el registro y seguimiento de gastos e ingresos personales, con sincronización automática a Google Sheets.

## 📋 Sobre el Proyecto

Sistema de gestión financiera desarrollado con **Flask** que permite registrar y categorizar movimientos económicos. Los datos se sincronizan automáticamente con Google Sheets para análisis y se respaldan localmente en SQLite.

**Tecnologías**: Python • Flask • SQLite • Google Sheets API • HTML/CSS/JavaScript

## ✨ Lo que Hace

- Registra gastos, ingresos y compras con tarjeta
- Categoriza movimientos por motivo y grupo
- Sincroniza automáticamente con Google Sheets
- Interfaz responsive para móvil y escritorio
- Base de datos local con SQLite
